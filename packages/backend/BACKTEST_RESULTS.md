## Recommendations

### High Priority
- **TD predictions remain challenging** - Low R2 for all TD models (0.5-0.78)
- Consider ensemble approach or additional features for TD prediction
- TD events are inherently volatile (game script dependent)

### Kicker/Defense Notes
- K/DEF models have lower accuracy due to:
  - Small sample sizes (32 teams x ~17 weeks vs hundreds of players)
  - High variance events (turnovers, special teams TDs)
  - Game script dependency (FG opportunities depend on stalled drives)
- Use wider prediction intervals for K/DEF positions
- Consider matchup-based adjustments for fantasy value

### Future Improvements
- Add game script features (home/away, spread, over/under)
- Consider player-level embeddings for boom/bust classification
- Ensemble models combining LightGBM + XGBoost for TD prediction
