## Technical Decisions

| Decision | Rationale |
|----------|-----------|
| Prediction intervals highest priority | MAPIE CQR provides guarantees with ~100 LOC |
| LightGBM before ensembles | 7x speedup enables experimentation first |
| Split conformal over MAPIE wrapper | Works with existing trained models without retraining |
| 90% confidence intervals | Informative bounds without excessive uncertainty |
| Accuracy % formula: 100*(1-MAE/mean) | Intuitive 0-100% scale for user trust |
| Team defense (not individual) | Fantasy uses team DST |
| FG buckets match ESPN (0-39, 40-49, 50+) | Aligns with fantasy point tiers |
| Player features from 2-season history | Sufficient data for reliable rolling stats |
| Explicit hex colors for Recharts | CSS variables use OKLCH which doesn't work with Recharts |
| Top 5 SHAP contributions shown | Most impactful factors first |
| Master-detail layout | Better space utilization than cramped grid |
| PPR scoring as default | Receptions count for fantasy points |
