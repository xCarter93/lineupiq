Create Avatar component following Shadcn UI patterns:

Props:
- src?: string (image URL, optional)
- alt: string (for accessibility)
- fallback: string (initials to show if no image, e.g., "PM" for Patrick Mahomes)
- size?: "sm" | "md" | "lg" (default "md")
  - sm: 32px (w-8 h-8)
  - md: 40px (w-10 h-10)
  - lg: 56px (w-14 h-14)
- className?: string (for additional styling)

Structure:
```tsx
<div className={cn("relative rounded-full overflow-hidden bg-muted", sizeClasses, className)}>
  {src ? (
    <img src={src} alt={alt} className="w-full h-full object-cover" onError={handleImageError} />
  ) : (
    <span className="flex items-center justify-center w-full h-full text-muted-foreground font-medium">
      {fallback}
    </span>
  )}
</div>
```

Features:
- Use Next.js Image component if available, but plain img is fine for external NFL CDN URLs
- Handle image load errors gracefully by falling back to initials
- Use Tailwind classes consistent with project (rounded-full, bg-muted, text-muted-foreground)
- Export from components/ui/avatar.tsx

Create horizontal bar component showing single feature contribution:

Props:
- displayName: string (e.g., "Recent Passing Yards")
- contribution: number (SHAP value, can be positive or negative)
- maxContribution: number (for scaling bar width)
- value?: number (optional: show the actual feature value)

Visual design:
- Bar extends left (negative/red) or right (positive/green) from center
- Width proportional to |contribution| / maxContribution
- Display name on left, contribution value (+/- format) on right
- Subtle background track showing the full range

Layout:
```
[Feature Name]          [-0.5] ████████░░░░░░░░░░░░ [+2.3]
                              ◄── negative | positive ──►
```

Simpler alternative (recommended for clarity):
```
Recent Passing Yards    ████████████░░░░░░░░  +15.2
Opponent Pass Defense   ░░░░░░████░░░░░░░░░░  -8.7
```

Colors:
- Positive: emerald-500 (or primary color)
- Negative: red-500 (or destructive color)
- Track: muted background

Use Tailwind for all styling. No external charting library needed — simple div width calculations.

Layout (per 17-CONTEXT.md — expandable):
1. Header: "Why this projection?" or "Prediction Breakdown"
2. Summary text (natural language from API)
3. Top 3-5 contribution bars (most impactful features)
4. "Show all factors" expand button
5. When expanded: show remaining contributions

Structure:
```tsx
<Card>
  <CardHeader>
    <CardTitle>Why {prediction} {targetDisplay}?</CardTitle>
  </CardHeader>
  <CardContent>
    <p className="text-muted-foreground mb-4">{summary}</p>

    <div className="space-y-2">
      {topContributions.map(c => (
        <FeatureContributionBar key={c.feature} {...c} maxContribution={maxContrib} />
      ))}

      <Button variant="ghost" onClick={() => setExpanded(true)}>
        Show {remainingCount} more factors
      </Button>

    {expanded && (
      <div className="space-y-2 mt-4">
        {remainingContributions.map(c => (
          <FeatureContributionBar key={c.feature} {...c} maxContribution={maxContrib} />
        ))}
      </div>
    )}
  </CardContent>
```
