```python
    model: XGBRegressor | LGBMRegressor,
    features: np.ndarray,  # shape (1, 28)
    feature_names: list[str],
    top_n: int = 6,
) -> dict:
```

Returns:
- `contributions`: list of {feature: str, contribution: float, direction: "positive"|"negative"} sorted by abs(contribution) descending
- `base_value`: float (expected value without features)
- `prediction`: float (final prediction)

Use SHAP TreeExplainer (already used in importance.py). Key difference from importance.py:
- importance.py aggregates across samples (mean absolute SHAP)
- explainability.py returns raw SHAP values for a single sample

Return raw SHAP contributions (not normalized) so UI can show "+42 yards from recent performance".

Handle both XGBoost and LightGBM models (both supported by TreeExplainer).

Create schemas for explainability response:

```python
# schemas/explainability.py
class FeatureContribution(BaseModel):
    feature: str           # Feature name (e.g., "passing_yards_roll3")
    contribution: float    # SHAP value (can be negative)
    direction: str         # "positive" or "negative"
    display_name: str      # Human-readable (e.g., "Recent Passing Yards")

class ExplainabilityResponse(BaseModel):
    position: str
    target: str            # Which stat we're explaining (e.g., "passing_yards")
    base_value: float      # Expected prediction without features
    prediction: float      # Final prediction
    contributions: list[FeatureContribution]  # Top N features
```
