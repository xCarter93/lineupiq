<task type="auto">
  <name>Task 2: Create explainability endpoint</name>
  <files>packages/backend/src/lineupiq/api/routes/explainability.py, packages/backend/src/lineupiq/api/main.py</files>
  <action>
Create new routes/explainability.py with POST endpoint:

POST /api/explain/{position}/{target}
- Accepts ExplainabilityRequest body
- Validates position is one of: QB, RB, WR, TE
- Validates target is valid for position (e.g., QB can have passing_yards, not receptions)

Implementation:
1. Load the trained model for {position}_{target} using existing load_model()
2. Prepare features using same prepare_features() as predictions
3. Call compute_shap_values(model, features) from importance.py
4. Get expected_value from the SHAP explainer
5. Make prediction using model.predict()
6. Build contributions list:
   - For each feature, get SHAP value
   - Look up display_name from FEATURE_DISPLAY_NAMES
   - Determine direction based on sign
   - Sort by absolute contribution (most impactful first)
7. Generate natural language summary (see Task 3 pattern)
8. Return ExplainabilityResponse

Register router in main.py with prefix "/api".

Valid targets by position:
- QB: passing_yards, passing_tds, interceptions, rushing_yards, rushing_tds, fumbles_lost
- RB: rushing_yards, rushing_tds, carries, receiving_yards, receptions, receiving_tds, fumbles_lost
- WR/TE: receiving_yards, receiving_tds, receptions, fumbles_lost
