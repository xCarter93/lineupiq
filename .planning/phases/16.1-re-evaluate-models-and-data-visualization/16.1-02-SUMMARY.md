### Task 1: Real vs Fake Player IDs

**Seed data (fake IDs):**
```typescript
// packages/frontend/convex/seedPlayers.ts
{ playerId: "mahomes-patrick", name: "Patrick Mahomes", ... }
{ playerId: "hurts-jalen", name: "Jalen Hurts", ... }
```

**Real gsis_ids from nflreadpy:**
```
Patrick Mahomes: 00-0033873
Jalen Hurts: 00-0036389
Josh Allen: 00-0034857
// ... etc
```

When API is called with fake ID "hurts-jalen", it returns 404 "Player not found".
When API is called with real ID "00-0036389", it returns full player history with `fantasy_points`.

### Task 2: Debug Logging

Not needed - Task 1 verification confirmed the issue is fake player IDs, not a code bug.

## Root Cause Summary

Both bugs from Phase 16.1 (identical predictions + empty chart) have the **same root cause**:

1. Seed players in Convex use human-readable fake IDs (`hurts-jalen`)
2. Backend APIs require real NFL `gsis_id` format (`00-0036389`)
3. API calls with fake IDs return 404, so no data is available

**Solution**: User must sync roster (Admin -> "Sync 2025 Roster") to get players with real gsis_ids.
