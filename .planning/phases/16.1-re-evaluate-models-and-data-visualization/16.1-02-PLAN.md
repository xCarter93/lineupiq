# Plan 16.1-02: Fix Chart Visualization

## Problem Statement

The Fantasy Points Trend chart shows X and Y axes but no data points or lines. This is because:
1. Sample seed players have fake IDs (`hurts-jalen`) instead of real gsis_ids
2. The `/api/player/{player_id}/history` endpoint requires real gsis_ids to fetch from nflreadpy
3. Without historical data, `fantasyPoints` is undefined, and the chart has no data to render

## Solution Overview

This is the same root cause as the prediction bug - fake player IDs. The fix requires using real synced players (from Admin → "Sync 2025 Roster"), OR updating sample players with real gsis_ids.
