     ```typescript
     'use client'
     import { useReportWebVitals } from 'next/web-vitals'

     export function WebVitals() {
       useReportWebVitals((metric) => {
         // Log in development for immediate feedback
         if (process.env.NODE_ENV === 'development') {
           console.log(`[Web Vitals] ${metric.name}:`, {
             value: Math.round(metric.name === 'CLS' ? metric.value * 1000 : metric.value),
             rating: metric.rating, // 'good' | 'needs-improvement' | 'poor'
             id: metric.id
           })
         }

         // TODO: Send to analytics in production (Vercel Analytics, GA4, etc.)
         // For now, just log to console
       })

       return null
     }
     ```

  2. **Add to layout.tsx:**
     - Import WebVitals component
     - Wrap in Suspense with null fallback
     - Place in RootLayout body (doesn't need to be visible)

  This captures Core Web Vitals: LCP (Largest Contentful Paint), FID (First Input Delay), CLS (Cumulative Layout Shift), FCP (First Contentful Paint), TTFB (Time to First Byte), INP (Interaction to Next Paint).
