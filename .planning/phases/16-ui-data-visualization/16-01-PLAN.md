<task type="auto">
  <name>Task 3: Create dynamic import wrappers for SSR safety</name>
  <files>packages/frontend/components/charts/index.tsx</files>
  <action>
Create centralized exports file with dynamic imports to prevent SSR hydration errors.

Export pattern from 16-RESEARCH.md:
```typescript
"use client";
import dynamic from "next/dynamic";

const ChartLoader = () => (
  <div className="h-[200px] flex items-center justify-center bg-muted/30 rounded-lg animate-pulse">
    <span className="text-sm text-muted-foreground">Loading chart...</span>
  </div>
);

export const FantasyPointsChart = dynamic(
  () => import("./FantasyPointsChart").then((mod) => mod.FantasyPointsChart),
  { ssr: false, loading: ChartLoader }
);
```

Key requirements:
- All chart components MUST use `ssr: false` to avoid hydration mismatches
- ChartLoader shows loading state with pulse animation
- Height matches chart height (200px) to prevent layout shift

Why dynamic imports: Recharts uses browser APIs (window, document) that break server-side rendering in Next.js.
