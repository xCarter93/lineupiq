## Key Insights

### Rolling Window Validation
1. **Overall Performance:** 5-game models show avg R² of 0.332 across 21 stats
2. **TD Predictions:** TD models avg R² of 0.261 - lower than volume stats but expected for volatile events
3. **Best Performers:** Carries (R² 0.696), passing yards (R² 0.524), rushing yards (R² 0.545), receptions (R² 0.46-0.59)
4. **Weakest Performers:** Fumbles lost (R² 0.008-0.121) - extremely rare events, hard to predict

### Feature Importance
1. **Rolling stats dominant:** Position-specific rolling averages (roll5) consistently rank in top 5
2. **TD models:** Rely heavily on prior TD rolling averages despite volatility
3. **Volatility metrics:** Less common in TD model top features (randomness can't be captured by volatility)
4. **Opponent features:** Appear in ~29% of model top 5, providing matchup context

### Data Leakage Fix Impact
The shift(1) fix ensures rolling features only use prior games:
- Week 1: null (no prior games)
- Week 2: avg of week 1 only
- Week 3: avg of weeks 1-2 only

This prevents models from "cheating" by seeing current game stats during training, making predictions more realistic.

## Technical Notes

### Benchmark Methodology
- Training window: 2022-2025 (4 years)
- Holdout season: 2025 (strict holdout, never seen during training)
- Model type: LightGBM with 30 Optuna trials per model
- Metrics: MAE, R², Normalized MAE

### SHAP Analysis
- TreeExplainer optimized for LightGBM
- Mean absolute SHAP value = feature importance
- Limited to 500 samples per model for performance
- Values normalized to sum=1.0 for comparability

### Rolling Window Implementation
```python
# With shift(1) - correct approach
rolling_avg = stats.rolling(window=5).mean().shift(1)
# Week 1: null (no prior games)
# Week 2: mean([week1])
# Week 3: mean([week1, week2])
# Week N: mean([N-5, N-4, N-3, N-2, N-1])
```
