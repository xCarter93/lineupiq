Expand rolling window from 3 to 5 games and retrain all models to capture recent performance trends better, especially for volatile stats like touchdowns.

Purpose: Current 3-game window is too narrow to capture meaningful patterns (e.g., Jalen Hurts: 1-3 TDs over last 5 games, model predicts 0.7). Expanding to 5 games should improve trend detection.
Output: All models retrained with 5-game rolling features, ready for validation benchmarking.
</objective>

  <files>packages/backend/src/lineupiq/features/rolling_stats.py, packages/backend/src/lineupiq/features/pipeline.py</files>
  <action>
Modify rolling window implementation:

**In rolling_stats.py:**
1. Change `compute_rolling_stats()` default parameter from `window: int = 3` to `window: int = 5`
2. Update docstring examples to reflect 5-game window
3. Update column naming to use `roll5` suffix (e.g., `passing_yards_roll5` instead of `roll3`)
4. Ensure shift(1) is maintained for leakage prevention (only prior games used, never current)

**In pipeline.py:**
1. Update `build_features()` call to `compute_rolling_stats()` to use new default (window=5)
2. Verify feature pipeline tests still pass with 5-game window
3. Add comment explaining rolling window expansion decision (reference to 19.1-CONTEXT.md)

**Why 5 games:**
- Captures meaningful trend patterns for TD predictions (Jalen Hurts example)
- Still recent enough to weight current form over distant history
- Balances signal strength with recency for volatile stats
- Provides more data points for early-season players than 3-game window

**What NOT to do:**
- Don't keep both 3-game and 5-game features (wholesale replacement, not additive)
- Don't change volatility calculations (rolling std, CV remain same methodology)
- Don't modify shift(1) leakage prevention

**Positions to retrain (32 models total):**
- QB: 6 targets (passing_yards, passing_tds, interceptions, rushing_yards, rushing_tds, fumbles_lost)

- TE: 4 targets (receiving_yards, receiving_tds, receptions, fumbles_lost)
- K: 5 targets (fg_0_39, fg_40_49, fg_50_plus, xp_made, fg_attempts)

- Extra: fumbles_lost model if not covered above

**Training data:** 2020-2025 (6 years) for maximum signal

**Training commands:**
```bash

uv run python -c "from lineupiq.models.defense import train_defense_models; train_defense_models()"
```
