<vision>
## How This Should Work

After implementing ensemble models in Phase 19, we discovered contradictory benchmark results that required deep investigation. The 2024 holdout showed single models winning 20/21 stats, while the 2025 holdout showed ensembles winning 20/21 stats - completely opposite conclusions.

The root cause wasn't about ensemble vs single models. It was about **training data quality and recency**:
- 2024 benchmark used 2-year training window (2022-2023)
- 2025 benchmark used 5-year training window (2020-2024) including COVID-era data
- Different training windows = fundamentally different learned patterns

**The Real Problem:** We need both better training data AND better features:

1. **Training Data Window:** Expand from 2 years (2022-2023) to 4 years (2022-2025)
   - Exclude COVID-era noise (2020-2021 had abnormal player usage patterns)
   - Include most recent 2025 season data for maximum recency
   - Balance volume (more examples) with relevance (recent NFL patterns)

2. **Rolling Window Features:** Expand from 3-game to 5-game rolling windows
   - Current 3-game windows too narrow for volatile stats (TDs, turnovers)
   - Example: Jalen Hurts threw 1-3 TDs over last 5 games, but model predicts 0.7 (only seeing 3 games)
   - 5-game window captures meaningful trends while staying recent

3. **Data Leakage Fix:** Add shift(1) to rolling stats (critical bug discovered)
   - WITHOUT shift(1): Rolling avg for Week 3 = mean(week1, week2, **week3**) ← includes game we're predicting!
   - WITH shift(1): Rolling avg for Week 3 = mean(week1, week2) ← only prior games
   - This was documented in STATE.md decision 13-02 but never actually implemented

This phase combines all three improvements to maximize model accuracy for 2026 predictions.

</vision>

## What Must Be Nailed

**Architectural Decision (from Plan 19.1-01):**
- Keep single models (reject ensembles despite 2025 benchmark)
- 2024 benchmark more reliable - matches production training approach
- Single models with good data beat ensembles with poor data

**Implementation Requirements:**
1. **Fix data leakage** - Add shift(1) to all rolling stats calculations
2. **Expand training window** - Update all models to train on 2022-2025 (4 years)
3. **Expand rolling window** - Update all features from 3-game to 5-game windows
4. **Retrain all 32 models** - QB (6), RB (7), WR (4), TE (4), K (5), DEF (5)
5. **Validate improvements** - Re-benchmark on 2024 holdout to confirm ≥ baseline performance

**Why This Matters:**
- Data leakage fix ensures model training matches real prediction scenarios
- Training data expansion provides more examples without COVID-era noise
- Rolling window expansion helps models see meaningful trends in volatile stats
- Combined effect should improve prediction accuracy, especially for high-impact stats like TDs

<notes>
## Additional Context

**Key Discovery from Plan 19.1-01:**
The "ensemble vs single models" debate was a red herring. The real insight was that training data quality (recency, volume, noise) matters more than architectural complexity. Simple models with clean, relevant data outperform complex ensembles trained on noisy data.

**Critical Bug Found:**
The shift(1) for data leakage prevention was documented in STATE.md (decision 13-02) but never actually implemented in the code. This means all models trained prior to Phase 19.1 were using future information (the current game's stats) to predict that same game - a form of data leakage that inflates training accuracy but hurts real prediction performance.

**Hybrid Approach:**
This phase takes the best of both benchmarks:
- From 2024 benchmark: Keep single models (simpler, no ensemble overhead)
- From 2025 benchmark: Expand training data (but exclude COVID-era 2020-2021)
- New addition: Fix data leakage and expand rolling windows

**Dependencies:**
- Phase 19: Ensemble implementation provided the benchmark comparison that revealed these issues
- Phase 13: Original LightGBM adoption and rolling feature engineering

**Impact on Future Phases:**
- All downstream features (Phase 20+) will benefit from cleaner rolling stats with shift(1)
- 2022-2025 training window becomes new standard for all future model updates
- 5-game rolling window becomes new baseline for feature engineering

</notes>
