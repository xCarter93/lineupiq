1. Models trained with window=5 features (Phase 19.1, see features/pipeline.py:144-155)

7. Result: All players use position-typical roll5 defaults → identical predictions

**Evidence from diagnostic script:**
[Include output showing the mismatch]

Change default window parameter from 3 to 5 in:
- `_compute_rolling_stats_for_player(history_df, window=5)`
- `_compute_volatility_for_player(history_df, window=5)`
- Update calls at lines 424, 425, 448, 449 to pass window=5
