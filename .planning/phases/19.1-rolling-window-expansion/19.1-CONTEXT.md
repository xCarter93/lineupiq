# Phase 19.1: Rolling Window Expansion - Context

**Gathered:** 2026-01-20
**Status:** Ready for planning

<vision>
## How This Should Work

After implementing ensemble models in Phase 19, there's a disconnect between recent player performance trends and model predictions. When looking at real examples like Jalen Hurts - who threw for at least 1 TD and peaked at 3 TDs over his last 5 games - the model only predicts 0.7 passing TDs for his next game (8.3 fantasy points total).

Recent performance should play a key role in predicting almost all stats. The current 3-game rolling window is too narrow to capture meaningful performance patterns, especially for volatile stats like touchdowns.

This phase shifts from 3-game to 5-game rolling windows across all features. By including more recent games (where available), models will have better signal for trend detection - distinguishing hot streaks from cold streaks, and making predictions that align with what we can see in recent performances.

</vision>

<essential>
## What Must Be Nailed

All aspects are equally important for this phase:

- **Accuracy improvement on TD predictions specifically** - Touchdown predictions (passing, rushing, receiving) have high fantasy impact and appear to be underperforming with current 3-game windows
- **Validating the 5-game window actually improves predictions** - Benchmark new 5-game rolling features against old 3-game baseline to confirm improvement before fully adopting
- **Understanding feature importance with new rolling window** - Analyze which rolling stats become more predictive with the larger window and whether it changes what features matter most

</essential>

<notes>
## Additional Context

**Key insight:** The Jalen Hurts example (recent 5-game trend: 1-3 passing TDs per game, model predicts: 0.7) crystallizes the problem. Users can see recent performance trends that the model isn't capturing.

**Implementation note:** This is a wholesale replacement from 3-game to 5-game rolling stats across all features, not an additive approach (not keeping both 3-game and 5-game).

**Dependency:** This phase was inserted after Phase 19, which successfully implemented ensemble models (weighted voting) that improved predictions after expanding training data to include more seasons.

</notes>
