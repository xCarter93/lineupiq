### Task 2: Validation Chart & Hook
**Agent:** ab05c42
**Commit:** e7b0496

Created ValidationChart component and useValidationPredictions hook:

**ValidationChart.tsx:**
- Recharts line chart showing predicted (blue) vs actual (green)

### Data Flow
1. User clicks player card in PlayerRepository
2. PlayerRepository sets selectedPlayer state
3. PlayerDrawer opens with player details
4. useValidationPredictions queries Convex for player's 2025 data
5. Hook groups predictions by target stat
6. ValidationChart renders each target as a line chart
7. Charts display predicted vs actual with accuracy metrics
