## Decisions Made

**1. Switched from walk-forward to holdout validation**
- Walk-forward: Retrain 18 times (before each week) = 12-24 hours
- Holdout: Train once on 2022-2024, predict all 2025 = 30-60 minutes
- ~20x speedup with equivalent scientific validity
- Proper temporal split prevents data leakage

**2. Add neutral Vegas features when API unavailable**
- Models trained with 40 features including home_spread, total_points (Vegas lines)
- When Odds API rate-limited/unavailable, feature count dropped to 36
- Solution: Always add Vegas columns with neutral values (spread=0.0, total=45.0)
- Maintains feature schema consistency across training and prediction

**3. Use 10 trials for quick validation**
- Production uses 30 Optuna trials per model
- Validation uses 10 trials for faster turnaround
- Still produces quality models (R² 0.585 average across all positions)
