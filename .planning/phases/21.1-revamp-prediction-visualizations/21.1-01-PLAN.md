<task type="auto">
  <name>Task 1: Create walkforward validation module</name>
  <files>packages/backend/src/lineupiq/models/walkforward.py</files>
  <action>
Create walkforward.py module with functions for time-series validation:

1. `retrain_models_through_week(season: int, week: int, positions: list[str])`:
   - Retrain all 32 models using data through specified week of specified season
   - Use train_all.py patterns but with dynamic season/week cutoff
   - Save models to temporary location (models_walkforward_{season}_week{week}/)
   - Return dict of model paths by position/target

2. `predict_week(season: int, week: int, model_paths: dict, positions: list[str])`:
   - Load player data for specified week from nflreadpy
   - Compute features for all active players in that week
   - Run predictions using provided model paths
   - Return DataFrame with columns: [player_id, player_name, position, season, week, target, predicted_value, actual_value]

3. `run_walkforward_validation(season: int, weeks: list[int], positions: list[str])`:
   - Orchestrates retraining and prediction for multiple weeks
   - For each week: retrain models through (week-1), predict week
   - Accumulate predictions across all weeks
   - Return combined DataFrame with all predictions vs actuals

Design principles:
- Reuse existing training infrastructure from train_all.py (Optuna, LightGBM defaults, 30 trials)
- Use backtesting.py patterns for loading holdout data
- Each week is predicted using ONLY data available before that week (proper time-series validation)
- Store models temporarily to avoid overwriting production models
