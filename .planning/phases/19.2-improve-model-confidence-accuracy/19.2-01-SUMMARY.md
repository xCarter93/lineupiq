## Decisions Made

### 1. R²-based accuracy as primary metric

**Formula:** `accuracy_pct = max(0, 100 * r2)`

**Rationale:**
- Standard ML metric (widely recognized)
- Perfect correlation with model quality by definition
- Works for all stat types (high/low mean, high/low variance)
- Fixes the "good model, bad metric" problem (R² 0.545 → 55% accuracy, not 47%)

### 2. Confidence tier thresholds aligned with R²

**Proposed logic:**
```python
if r2 > 0.5:
    return "High"
elif r2 > 0.3:
    return "Medium"
else:
    return "Low"
```

**Rationale:**
- Current logic requires both R² > 0.5 AND accuracy_pct > 80%, which is impossible with MAE/mean formula
- New logic aligns confidence directly with explained variance
- Results in 9 model upgrades (Low → Medium), 1 downgrade (High → Medium)

### 3. Keep skill score as optional secondary metric

**Formula:** `skill_score = 100 * (1 - MAE / std)`

**Rationale:**
- Variance-normalization helps for high-volatility stats (TDs, fumbles)
- Could be displayed as "Consistency" metric alongside "Accuracy"
- Not needed immediately, can be added in Phase 19.2-03
