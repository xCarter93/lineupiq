  <files>packages/backend/src/lineupiq/models/accuracy.py</files>
  <action>
    Modify calculate_model_accuracy() function:

    **Current formula (REMOVE):**
    ```python
    if mean_actual != 0:
        accuracy_pct = max(0.0, 100.0 * (1.0 - mae / abs(mean_actual)))
    else:
        accuracy_pct = max(0.0, 100.0 * r2) if r2 > 0 else 0.0
    ```

    **New formula (IMPLEMENT):**
    ```python

    accuracy_pct = max(0.0, min(100.0, 100.0 * r2))
    ```

    **Rationale:**
    - R² already calculated, no additional computation
    - Directly represents "how much variance the model explains"
    - Clamp to [0, 100] range (R² can be negative for very poor models)
    - Remove mean_actual != 0 check (no longer needed)

    **Update docstring:**
    - Change "accuracy_pct: 100 * (1 - MAE / mean(actuals))" to "accuracy_pct: 100 * R² (variance explained)"
    - Update example to reflect R²-based calculation
  </action>
  <verify>accuracy.py uses accuracy_pct = max(0.0, min(100.0, 100.0 * r2))</verify>
