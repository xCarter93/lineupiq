## Decisions Made

### 1. R²-based accuracy formula with clamping

**Formula:** `accuracy_pct = max(0.0, min(100.0, 100.0 * r2))`

**Rationale:**
- R² already calculated, no additional computation
- Directly represents "variance explained" (0-100%)
- Clamp to [0, 100] range (R² can be negative for very poor models)
- Fixes the "49% accuracy for R² 0.545" problem

### 2. Simplified confidence tier logic

**New thresholds:**
```python
if r2 > 0.5:
    return "High"      # Explains >50% variance
elif r2 > 0.3:
    return "Medium"    # Explains 30-50% variance
else:
    return "Low"       # Explains <30% variance
```

**Rationale:**
- Single metric (R²) for confidence (was: R² AND accuracy_pct)
- Aligns with ML standards: R² > 0.5 is good, 0.3-0.5 is acceptable
- Removes confusing dual-threshold (R² OR accuracy_pct)

### 3. Comprehensive test coverage

**Test categories:**
1. R² → accuracy_pct mapping (perfect, good, poor predictions)
2. Edge cases (negative R², R² > 1)
3. Confidence tier boundaries (0.5, 0.3 exact thresholds)
4. Backtest aggregation (empty, single, multiple models)

**Rationale:**
- Validates formula correctness across all scenarios
- Ensures clamping works for edge cases
- Confirms confidence tiers align with R² thresholds
- Prevents regression when updating accuracy logic
