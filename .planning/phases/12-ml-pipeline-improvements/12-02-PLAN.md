Create `uncertainty.py` module implementing prediction intervals with MAPIE:

1. `create_interval_model(base_model: XGBRegressor, X: np.ndarray, y: np.ndarray, alpha: float = 0.1) -> MapieRegressor`:
   - Wrap base XGBoost model with MapieRegressor

   - Fit the MAPIE wrapper on training data
   - Return the fitted MapieRegressor

2. `predict_with_intervals(model: MapieRegressor, X: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]`:
   - Call model.predict(X)
   - Return tuple of (point_predictions, lower_bounds, upper_bounds)
   - Handle single prediction (1 sample) and batch predictions

3. `format_interval_response(point: float, lower: float, upper: float) -> dict`:
   - Format for API response:
     ```python
     {
       "prediction": round(point, 1),
       "interval": {
         "lower": round(lower, 1),
         "upper": round(upper, 1),
         "confidence": 0.9  # Fixed at 90%
       }
     }
     ```

4. `calculate_interval_width(lower: np.ndarray, upper: np.ndarray) -> np.ndarray`:
   - Simple helper: upper - lower
   - Useful for tracking interval quality

**Import pattern:**
```python
from mapie.regression import MapieRegressor
from xgboost import XGBRegressor
```

**NOTE:** MAPIE requires fitted base model. For inference with existing models, we need to either:
- Re-fit with MAPIE wrapper (adds training time but enables intervals)
- Use a "split conformal" approach with calibration data

For v1, use split conformal approach: reserve some data for calibration, use that to compute residuals and intervals. This works with already-trained models.

Actually implement option 2 (split conformal) since we have pre-trained models:

```python
def calibrate_intervals(model: XGBRegressor, X_cal: np.ndarray, y_cal: np.ndarray, alpha: float = 0.1) -> tuple[float, float]:
    """Compute conformal prediction intervals using calibration set residuals."""
    y_pred_cal = model.predict(X_cal)
    residuals = np.abs(y_cal - y_pred_cal)
    # Quantile for (1-alpha) coverage
    q = np.quantile(residuals, 1 - alpha)
    return q  # Add/subtract this from predictions for intervals
```

This is simpler and works with our existing joblib-saved models.
