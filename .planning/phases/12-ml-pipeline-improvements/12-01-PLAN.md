<task type="auto">
  <name>Task 2: Create accuracy metrics module</name>
  <files>packages/backend/src/lineupiq/models/accuracy.py</files>
  <action>
Create `accuracy.py` with functions to compute model-level accuracy metrics:

1. `calculate_model_accuracy(predictions: np.ndarray, actuals: np.ndarray) -> dict`:
   - Compute: MAE, RMSE, R2 (reuse from evaluation.py)
   - Compute **accuracy percentage**: 100 * (1 - (MAE / mean(actuals)))
     - This gives a 0-100% score where 100% = perfect predictions
   - Compute **directional accuracy**: % of predictions where predicted direction matches actual (above/below mean)
   - Return dict with all metrics including accuracy_pct, directional_accuracy

2. `calculate_confidence_rating(r2: float, accuracy_pct: float) -> str`:
   - Return confidence tier: "High" (r2 > 0.5 and accuracy > 80%), "Medium" (r2 > 0.3), "Low" otherwise
   - This is a user-friendly summary of model reliability

3. `summarize_backtest_results(backtest_results: list[dict]) -> dict`:
   - Aggregate results by position and by target stat
   - Compute overall model confidence across all models
   - Structure for easy API consumption:
     ```python
     {
       "overall_accuracy_pct": float,
       "overall_confidence": str,  # High/Medium/Low
       "by_model": [
         {"position": "QB", "target": "passing_yards", "accuracy_pct": 75.2, "confidence": "Medium", ...},
         ...
       ]
     }
     ```

Follow existing patterns from evaluation.py for metric calculation.
